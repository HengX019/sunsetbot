# 朝霞晚霞预测

**HengX 公益制作，给摄影爱好者的一份看天参考。**

因原网站已无法继续使用，我制作了这个朝霞、晚霞预测网页，希望大家在拍摄前能方便地看看当地的火烧云条件。项目在 GitHub 公开源码，免费提供使用，不以本网站进行盈利。

页面采用单文件 HTML，下载后即可打开，也可以部署到自己的静态服务器。

> 界面参考 Sunsetbot，预测使用本项目的独立近似模型。本站与 Sunsetbot 及其作者无隶属或合作关系，未取得原站完整算法，无法保证预测结果与原站一致。

## 功能

- **自动显示当地晚霞**：关闭访问声明后，根据访问者的公网 IP 识别大致城市，查询今天的晚霞。
- **中文城市搜索**：支持城市、区县和拼音搜索，候选按“省份 - 城市 - 区县”显示，点击即可查询；也可使用城市索引逐级选择。
- **朝霞 / 晚霞切换**：支持今天、明天的日出和日落预报，可切换 GFS、EC 数据源。
- **火烧云鲜艳度参考**：用粉紫色文字显示“可能小烧”“可能中烧”等本地估算结果。
- **天空通透度参考**：显示气溶胶光学厚度 AOD，符合条件时标注“水晶天”“高级水晶天”。
- **主页双小地图**：并排查看当地周边的朝霞、晚霞分布，点击可进入大地图。
- **区域地图自动更新**：拖动、缩放后自动读取当前视野，使用连续色块和等值线展示区域强弱。
- **详细预报与查询记录**：查看分层云量、能见度及大气截面示意，保存本浏览器最近 10 次查询快照。
- **手机适配**：支持触屏操作和窄屏布局。

## 快速开始

下载 `index.html`，用浏览器打开即可。

运行网页不需要安装 Node.js、数据库或构建工具。页面样式、脚本、地图库和简化底图均已内嵌；**实时预报仍需联网获取天气和气溶胶数据**。

推荐通过 HTTP(S) 访问。如果直接双击打开时出现跨域或存储限制，可在文件所在目录启动本地预览：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

然后访问 [本地预览](http://127.0.0.1:8080/)。

### 使用方法

1. 阅读免责声明，点击“我已了解，进入网站”。
2. 等待 IP 大致定位，或自行搜索并选择城市、区县。
3. 选择今天 / 明天、朝霞 / 晚霞及数据源，查看文字判断与 AOD。
4. 通过主页小地图查看周边分布，点击小图放大；大地图拖动、缩放后会自动更新。
5. 需要更多信息时，查看“详细预报”“大气截面”或“关于”。

IP 定位结果单独显示，搜索框初始留空。定位只到城市时会标注“区县未知”，不会把城市中心点当成你的精确位置。

## 部署

发布文件可以保持为：

```text

├── index.html

```

### 静态服务器

把 `index.html` 上传到 Nginx、Apache 或其他静态托管服务的站点目录即可。默认配置下无需后端服务，也无需地图 API 密钥。

### GitHub Pages

将 `index.html` 放在仓库根目录，在仓库的 **Settings → Pages** 中配置发布来源，选择包含该文件的分支和目录。部署完成后，通过 Pages 提供的网址访问。

如果你的网页仍放在 `outputs/` 等子目录中，需要先将发布文件移到所选发布目录，或配置工作流发布该目录。具体操作参见 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

### 自建数据接口

默认由访问者浏览器直接请求公共接口。站长如需使用兼容服务或同源代理，可修改 `index.html` 中的 `DEFAULTS` 配置：

| 配置项 | 用途 |
| --- | --- |
| `weather` | 云量、能见度等天气预报 |
| `air` | 气溶胶光学厚度 AOD |
| `geo` | 在线地名搜索 |
| `ip` | 访问者 IP 大致定位 |

天气和气溶胶代理需保留兼容的查询参数与 JSON 响应，并支持多地点坐标请求。需要服务端密钥时，应将密钥保存在服务器端。

若使用自建 IP 定位接口，请按访问者的真实连接信息查询；让服务器请求“查询自身 IP”的服务，会得到服务器的位置。

## 怎样理解预测结果

### 火烧云鲜艳度

火烧云需要合适的云层作为“画布”，也需要太阳方向有足够的光照到云上。本地模型结合中高云云量、低云遮挡、沿线受光、能见度和气溶胶，给出相对强弱判断。

页面保留“本地估算”标记，**不显示或换算 Sunsetbot 原版鲜艳度数值**。“可能小烧”“可能中烧”等标签未经实况校准，不代表发生概率。

### AOD 与水晶天

AOD 表示气溶胶对光线的消光程度，通常越低，空气越通透。它不是空气质量指数 AQI。

本项目的参考标签采用以下条件：

| 标签 | 条件 |
| --- | --- |
| 水晶天 | AOD ≤ 0.10，且能见度 ≥ 25 km |
| 高级水晶天 | AOD ≤ 0.05，且能见度 ≥ 30 km |

上述阈值为本项目的参考规则，**不是原站的分级标准**。缺少 AOD 或能见度时，不标注水晶天。空气通透也不代表一定有火烧云。

### 地图色块

粉紫色越深，表示本地近似模型的火烧云条件越好。无色区域可能表示条件较弱；缺测区域也会留空，需结合加载提示判断。

地图使用稀疏气象采样与空间插值，放大不会增加原始天气数据的精度，局地云洞、山体遮挡和短时天气变化可能无法体现。等值线与色块来自同一个插值场。

## 数据与算法

| 内容 | 来源 |
| --- | --- |
| 云量、能见度等天气数据 | [Open-Meteo](https://open-meteo.com/en/docs) 提供的 NOAA GFS / ECMWF IFS |
| 气溶胶 AOD | [CAMS Global，经 Open-Meteo 提供](https://open-meteo.com/en/docs/air-quality-api) |
| 城市与区县索引 | [AreaCity](https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov) |
| IP 大致定位 | IPIP，备用 GeoJS / IP.SB |
| 地图组件 | [Leaflet](https://leafletjs.com/) |
| 简化地理底图 | [Natural Earth](https://www.naturalearthdata.com/) / [DataV.GeoAtlas](https://help.aliyun.com/zh/datav/datav-atlas/developer-reference/atlas-sdk-introduction) |
| 可选街道底图 | [OpenStreetMap](https://www.openstreetmap.org/copyright) |

单点模型在太阳方向上选取 80 / 180 / 300 / 450 / 600 km 五个位置，结合分层云量、地球曲率下的近似光路、能见度和 AOD 估算受光条件。太阳位置计算参考 [NOAA 太阳计算说明](https://gml.noaa.gov/grad/solcalc/calcdetails.html)。

区域地图使用 7×7 个观测点，从覆盖观测点及方向采样位置的 11×11 气象场插值云况；主页朝霞、晚霞小图共享区域取数，分别计算日出与日落。

模型没有完整描述真实云底、云光学厚度、云相态、三维云结构、气溶胶垂直分布、地形和折射影响。公式、系数及适用范围可在网页“关于 → 算法、公式与限制”中查看。目前没有足够的实况回测，无法给出预测准确率。

## 网络与隐私

- 页面不申请设备 GPS 权限，不保存原始 IP。
- 调用到的 IP 定位服务会接收访问者公网 IP；近似坐标会用于天气查询。
- 查询偏好、最近记录和预报缓存保存在当前浏览器，不会在设备间自动同步。
- IP 定位可能受移动网络出口、VPN、代理和数据库误差影响，位置不准时可手动选择。
- 预报缓存有效期为 30 分钟。地图请求失败或限流时，会提示并自动重试。
- 页面没有登录系统，也没有统一收集所有访客查询记录的后端；第三方服务及你所使用的托管服务可能有各自的访问日志。

公共接口的速度、额度及在不同网络下的可用性可能变化。自行部署时，请遵守相关数据源和托管服务的使用条款。

## 常见问题

**打开网页后为什么没有自动定位？**

先关闭访问声明，再等待定位结果。若定位服务不可用，页面会提示并回退到上次查询城市；没有历史记录时使用默认城市。可直接搜索地点继续使用。

**地图为什么有空白或加载较慢？**

天气接口可能出现缺测、网络失败或限流。页面会自动补取；快速拖动时也会取消旧请求，优先加载最后停留的视野。无色区域还可能表示火烧云条件较弱。

**可以完全离线使用吗？**

内嵌的页面、城市索引和简化底图可以离线读取，实时预报需要联网。

**预报显示可能大烧，为什么现场没有？**

本地模型与天气模式都有误差，尤其难以描述局地云层、遮挡和短时变化。建议结合现场天空、卫星云图及其他天气信息判断。
